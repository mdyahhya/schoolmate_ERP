# School ERP — Offline Desktop Application

An offline-first commercial School ERP Desktop Application built with Electron, Vanilla JS, and SQLite.

## Features
- **Offline Multi-Language (i18n)**: English, हिन्दी (Hindi), मराठी (Marathi), ಕನ್ನಡ (Kannada), and اردو (Urdu) with automatic RTL support.
- **Student Information & Admissions**: Complete directory, registration, search, and filtering.
- **Teacher & Staff Management**: Faculty directory, designations, and contacts.
- **Daily Attendance Tracking**: Student and staff attendance logging.
- **Academics & Timetable**: Classes, sections, subjects, and schedule planner.
- **Exams & Results**: Examination schedules, marks recording, and grading.
- **Fees & Financial Management**: Fee structure, receipt generation, and collection ledger.
- **Notices & Communication**: Circulars and announcements broadcast.
- **Transport & Hostel**: Route tracking, vehicle register, and room allocations.
- **Reports & Settings**: Dynamic printable reports and theme accent color customizer.

---

## Installation & Setup

All required libraries and dictionaries are already bundled and configured in `package.json`.

### 1. Install All Dependencies
Run this single command in your terminal:
```bash
npm install
```

### 2. Start the ERP Software
```bash
npm start
```

---

## Multi-Language Switching (Offline)
- Select your desired language (**English**, **हिन्दी**, **मराठी**, **ಕನ್ನಡ**, **اردو**) from the top-right header dropdown at any time.
- All module titles, navigation links, buttons, and form labels will immediately translate **100% offline without any internet connection**.
